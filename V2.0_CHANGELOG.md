# V2.0 Changelog

## Correctness and experiment infrastructure

- Engine carries previous iteration runtime, compute-utilization estimate and token count into the next State snapshot.
- Mixed profiling appends every feasible context point inside the context loop; corrected grid has 115 mixed points rather than 20.
- SLOA TTFT risk includes waiting and prefill-in-progress requests; TPOT risk includes a predicted next decode-only iteration.
- SLOA tilt changes effective chunk and token budget; budget target is bounded to the Engine's 2048-token cap.
- Zero-risk state returns balanced; controller state resets between independent runs.
- Arrival and request-mark RNG streams are separated; MMPP and stepped arrival multipliers are normalized; step traces extend through the full horizon.
- Finite traces are time-scaled to match target rho exactly while preserving relative arrival-time shape.
- Added V1-emulated baseline, multi-workload experiment runner, ablation/chunk/parameter sweeps and result finalizer.

## Validation boundary

- Six regression tests pass.
- 720 main-matrix runs and 87 additional ablation/sweep runs are simulator outputs.
- Not a real 2×RTX 3090 benchmark; reference profiling comes from a different GPU platform.
- SLOA predictive TTFT risk still uses a representative one-iteration prefill estimate; V3 proposes multi-chunk completion-time prediction.
