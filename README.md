# Alibaba DeepSeek Single-Instance Inference Simulator — V2.0

This repository contains the V1 baseline and the V2.0 SLOA scheduling fixes for a TP=2 single-instance LLM inference simulator.

> **Evidence boundary:** results generated by this repository are simulator outputs unless explicitly labelled as real-hardware measurements. The current V2.0 validation is compile + smoke-test validation, not a full benchmark and not a 2×RTX 3090 measurement.

## V2.0 changes

- TTFT risk population includes both waiting and prefill-in-progress requests.
- TPOT risk includes a one-iteration decode-time look-ahead.
- TTFT-first / TPOT-first tilt now changes effective prefill token budget and chunk target.
- SLOA controller state is reset between independent runs.

## Quick start

```bash
pip install -r requirements.txt
python -m compileall -q src scripts
python scripts/00_smoke.py
```

## Repository layout

- `src/`: simulator, cost model, predictors and schedulers.
- `scripts/`: smoke test and experiment entry points.
- `data/`: calibration, profiling and experiment data.
- `figures/`: generated plots.
- `refs/`: paper notes and modelling references.
- `V2.0_TODO.md`: unified pending-work checklist.
- `V2.0_CHANGELOG.md`: V2.0 fixes and validation boundary.
- `results/v2_smoke/`: V2.0 smoke-test output.

## Important limitations

The predictive SLOA controller currently uses one-iteration look-ahead. It is not yet a full queueing-time predictor. Its tilt scaling factors are initial heuristics and require sensitivity analysis. See [V2.0_TODO.md](V2.0_TODO.md) before interpreting results.
