# V2.0 Follow-up Experiments

## Scope

- 720 paired main-matrix runs: W1–W6 × rho {0.25, 0.65, 0.85, 1.20} × 3 seeds × 10 policies.
- 87 additional runs: SLOA ablation, fixed-chunk sweep, risk-threshold × gamma sweep.
- Corrected profiling grid: 46 decode + 60 prefill + 115 mixed = 221 points; 19,890 synthetic samples.
- Six regression tests pass.

> All metrics below are simulator outputs. The target 2×RTX 3090 / Qwen3-32B W4A16 configuration is assumed, not real-hardware benchmarked. The reference profile bundle comes from a different GPU platform.

| Comparison | Mean delta | 95% CI |
|---|---:|---:|
| SLOA-V2 − SLOA-V1-emulated | -0.0009 | [-0.0129, 0.0067] |

V2 has not shown statistically significant Goodput gains over V1-emulated or SLOWEAVE. It does show a positive macro paired difference over Fixed-64+SPF.

## Ablation (W3-Mixed, rho=0.85, 3 seeds)

| Variant | Goodput req/s | TPOT P99 ms |
|---|---:|---:|
| Full | 0.162 | 645 |
| No Dual Tilt | 0.173 | 706 |
| No Priority Score | 0.186 | 629 |
| No Util Knobs | 0.162 | 823 |
| No TPOT Constraint | 0.113 | 1,720 |

The TPOT hard constraint is the strongest current component. The current linear Priority Score and discrete Dual Tilt hurt this ablation result.

## Chunk sweep

At W3-Mixed / rho=0.85, Fixed-64 obtains 0.185 req/s Goodput versus 0.162 for SLOA Full. V2 has not demonstrated superiority over a tuned static chunk in every workload.

## Main conclusions

1. Engine feedback propagation, mixed profiling grid, load normalization and effective budget behavior have been fixed.
2. V2 and V1-emulated are statistically tied in Goodput; V2 has lower macro TPOT P99.
3. SLOA's TPOT hard cap matters; the current linear priority and dual tilt need redesign.
4. TPOT-first appears in only about 0.4% of SLOA ticks, indicating that Decode-only risk prediction misses Prefill interference.
5. W7-Adversarial was excluded from the main matrix because 40k-token whales/long outputs are expensive and small traces weaken P99 confidence.

## V3 direction

Implement SLOA-MPC: request-level TTFT/TPOT deadline slack, candidate mixed-iteration P99 risk, joint Decode Batch + Prefill Budget/Chunk search, uncertainty-aware runtime prediction, continuous risk weights with hysteresis, and compute/memory/KV/queue-aware feedback. See `V3_DESIGN.md`.
